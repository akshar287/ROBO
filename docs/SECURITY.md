# ROBO Security Architecture & Privacy Policy

ROBO is engineered with a strict **Privacy-First, Zero-Exfiltration** philosophy.

---

## 1. Zero Developer Credentials Stored

* **No WhatsApp Cloud API tokens** or private keys are stored.
* **No telecom VoIP credentials** or passwords required.
* User communications are handled via native device intents (`Intent.ACTION_DIAL`, `whatsapp://send`), keeping your conversations encrypted within your official personal apps.

---

## 2. Desktop Sandbox Restrictions

The Windows Desktop Agent restricts file system interactions to a dedicated sandbox folder:
```
C:\Users\<User>\Desktop\RoboFiles\
```
* **Path Traversal Protection**: Any path containing `..` or attempting to access `C:\Windows` or system directories is blocked and logged as a security violation.
* **Application Allowlist**: Only explicitly whitelisted applications (`chrome`, `notepad`, `calc`, `spotify`, `vscode`) may be launched. Arbitrary shell commands generated by AI are never executed.

---

## 3. Human-in-the-Loop Approval Gates

Before any of the following actions can execute:
* Sending an email or reply draft
* Placing external calls
* Modifying sensitive files

The action enters the **Approval Queue** with status `pending_approval`. The web dashboard displays the exact parameters (recipient, message text, subject). Execution only occurs after the user clicks **"Approve & Execute"**.

---

## 4. Emergency Stop

* The master ON/OFF toggle in the top bar acts as an instant emergency halt.
* Setting state to `OFF` immediately broadcasts to all connected Android and Laptop clients, causing them to reject and abort pending actions.
